# LOVE20BSC 代码迁移规范

本文件用于把 `LOVE20TKM` 代码迁移到新的 BSC 代码库，**只写迁移专属**的流程与约束。工具链与依赖、接口设计、事件、集合读取、命名、注释、`init`、复用、部署脚本等通用规则见 [合约开发规范](dev-standards.md)——迁移同样必须遵守那些规则。

## 一、开工顺序

1. 固定旧仓库提交；旧仓库只读。
2. 三层 ABI 对账：函数、事件、错误、结构体、枚举逐项标记为**保留 / 改名 / 改参 / 删除 / 新增**。
3. 建目标代码库最小骨架，先确认编译与跨仓库 import。
4. 一次只实现一个代码库、一个合约。

## 二、单合约实施步骤

每个合约按序推进，产出四个提交：

1. **规格与接口 Review** —— 确认设计合理性、变更必要性、命名、顺序与旧行为去向；规格只是参考，不一致不自动判错。
2. **旧代码基线** —— 从固定旧提交复制原实现与接口文件并提交（不要求可编译），再重命名为迁移后文件名并提交，便于后续看变更 diff；不带入已裁决删除的无关依赖或已完成迁移的合约。
3. **BSC 实现** —— 在重命名基线上完成 BSC 改造；先编译并展示 diff，确认后提交。尽量保持原顺序与格式，减少无谓 diff。
4. **单元测试** —— 以行业最高标准完成，review 并解决相关问题后提交。

四个提交：**旧代码基线、重命名、BSC 实现、单元测试**。

## 三、规格与接口 Review

当前规格是阶段性参考，不是不可推翻的标准。旧行为、当前规格、BSC 目标不一致时，不应只因"规格写过"就拒绝修改，也不应只因"旧代码如此"就照搬。

每项变更按序判断：

1. 原始需求与 BSC 目标是否真的需要它；
2. 旧代码实际做了什么——哪些行为是必要不变量、哪些只是历史实现；要移除的接口是否真有必要，还是应改为其他接口；
3. 新行为是否更合理、更安全、更易实现或维护；
4. 影响是否覆盖 ABI、权限、资产、事件、错误、历史与下游依赖。

确认决策后，再同步 `interfaces/`、模块规格与迁移对账文档。规格与实现暂时不一致，首先是待决策项，不自动判定为实现缺陷。

## 四、迁移期的接口组织

- 旧接口若按 `Events`、`Errors` 和主接口拆分声明，新接口默认保留相同的拆分结构、声明顺序与文件布局；除非规格明确要求，不得在迁移时同时改变接口组织方式。
- `I<Name>Errors` 子接口的有无、以及它与 `I<Name>Events` 的相对顺序，按旧文件确定（`I<Name>Events` 的拆分见[开发规范](dev-standards.md#41-接口文件与声明)）。
- 实现前，自有接口在 `matt-gov/interfaces/<repo>/` 冻结，作为 ABI 对账的基准；仓库实现完成后接口迁入该仓库的 `src/interfaces/`、删除 matt-gov 的副本，规格正文的链接改为指向该仓库（`core`、`action` 已按此完成，`group-chat` 待其仓库创建）。
- 对账文档须区分「自有声明」与「完整 ABI（含继承成员）」两种口径。

## 五、迁移期的实现约束

- 保持旧代码的声明顺序、状态变量顺序、函数顺序与格式，除非 BSC 规格明确要求改变。这条服务于**人工 review**，不是 diff 行数：整体重写时重排不会让 diff 变小，能改善的是新旧文件可逐成员对照。
- 保持旧接口中错误、事件、状态变量与函数的相对顺序；新增成员放在最接近其语义的位置，避免把参数变化误读为新增接口。
- 保留旧命名；只有协议语义明确变化时才改名。常量及其 getter 默认保持旧的大写命名。
- 纯排版整理（重排成员、展开声明）须证明语义未变：整理前后编译产物的**运行时代码与 ABI 逐字节一致**，并重跑 `forge build` 与全部测试。模块尚无测试时不得顺手改语句级写法（循环形状、`if`/`revert`、`unchecked`），留到测试提交之后。
- 先删除已裁决移出的业务与依赖，再补入 BSC 必需内容；不复制不会使用的旧合约、库或外部接口。
- 迁移期可额外保留旧接口已有的单值读取入口，不必按[开发规范](dev-standards.md#43-集合读取函数)第 6 条的三种理由重新论证；其余读取路径规则照常适用。

## 六、迁移期的审查证据

除[开发规范](dev-standards.md#二审查证据)的通用检查外，迁移提交前还须检查：

- ABI 与对账表一致；
- 旧行为的保留项没有无意变化；
- 工作树干净，提交只含本步内容。

旧行为差异必须能追溯到当前规格或迁移决策；不得把"能编译"当作迁移完成。
