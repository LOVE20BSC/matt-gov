# 发射 NFT 与子币发射

Type: grilling
Status: open
Blocked by: 01, 05

## Question

定义治理激励铸造量达到“剩余未铸造量百分比”后获得发射额度的公式、额度消耗和并发边界；`LOVE20LaunchNFT` 的铸造、转让、永久锁定到子币合约、发射关系记录和不可重复使用规则；去中心化发射与中心化发射的授权差异；其他链已发射子币作为保留代币但不可触发发射的识别规则。

## Comments

用户补充确认：BSC 版公平发射由 `LOVE20LaunchNFT` 持有者执行；发射时可指定首次分配的接收钱包或合约，由接收方自行二次分配。父币托底池以及底层核心中的父币申购逻辑不再存在；父币申购作为 `launch` 代码库中多种公平发射初始分配机制之一实现。
