# 体验资产与行动撤回

Type: grilling
Status: resolved
Blocked by: 01, 02

## Question

定义体验模式中自有资产与体验资产的标识、额度、混合参与、撤回顺序和到期处理；行动支持部分撤回时的参与权、验证分数、激励资格和剩余资产计算；执行合约失效、用户主动退出和行动结束后的共同结算规则。

## Comments

用户确认：体验资产按 `tokenAddress + memberId + actionId + provider` 独立记账；体验资产归提供者所有，退出时返还对应提供者。自有资产与体验资产可以同时存在，部分撤回只减少指定账本，不互相抵扣，也不影响另一类资产。

用户确认：部分撤回以行动自身的验证/激励快照为边界；快照前撤回减少当轮参与权、验证权重和可得激励，快照后撤回不追溯修改当轮验证集合、验证结果或激励，只影响后续轮次；余额归零后才清除该 `memberId` 的行动参与登记。

用户确认：行动结束不由 `ActionTarget` 自动结算；正常退出、资产返还和参与登记清理由行动类型内部业务完成。执行逻辑失效时，首版部署的 `forceExit` 仅允许当前 `MemberNFT` 持有人清理通用参与登记并发出事件，不保证资产返还，前端首版隐藏该入口。

## Answer

- **资产账本**：体验资产按 `tokenAddress + memberId + actionId + provider` 独立记账，体验资产归提供者所有；退出时返还对应提供者。自有资产与体验资产可以同时存在，部分撤回只减少指定账本，不互相抵扣。所有可复用行动执行合约的状态都必须带 `tokenAddress + actionId + ActionRound` 作用域，避免跨社区碰撞。
- **部分撤回**：以行动自身的验证/激励快照为边界。快照前撤回减少当轮参与权、验证权重和可得激励；快照后撤回不追溯修改当轮验证集合、验证结果或激励，只影响后续轮次。余额归零后清除该 `memberId` 的行动参与登记。
- **正常退出**：加入、部分撤回、全部退出和资产返还均由提案类型内部业务定义和执行，`ActionTarget` 不托管资产。
- **行动结束**：不由 `ActionTarget` 自动结算；内部业务负责结束后的资产返还、激励铸造和登记清理。
- **执行失效**：首版部署 `forceExit(tokenAddress, actionId, memberId)` 作为最后兜底，仅允许当前 `MemberNFT` 持有人调用，清理通用参与登记并发出事件，不调用失效业务，也不承诺返还资产；前端首版隐藏该入口。
