# 体验资产与行动撤回

Type: grilling
Status: claimed
Blocked by: 01, 02

## Question

定义体验模式中自有资产与体验资产的标识、额度、混合参与、撤回顺序和到期处理；行动支持部分撤回时的参与权、验证分数、激励资格和剩余资产计算；执行合约失效、用户主动退出和行动结束后的共同结算规则。

## Comments

用户确认：体验资产按 `memberId + actionId + provider` 独立记账；体验资产归提供者所有，退出时返还对应提供者。自有资产与体验资产可以同时存在，部分撤回只减少指定账本，不互相抵扣，也不影响另一类资产。
