# LOVE20BSC Matt Governance

本仓库维护 LOVE20BSC 的组织级协作与迁移资料，由 Matt 技能维护。

## 范围

- 旧组织到新组织的仓库迁移、合并、删除和归档决策
- 跨仓库协议设计、依赖关系、发布顺序和验收标准
- Wayfinder 决策地图、票据和已确认结论
- 组织级协作规范、CONTEXT 和 ADR

## 不放在这里

- Solidity、TypeScript 或前端业务代码
- 各代码库自己的详细业务文档和测试
- 只影响单个代码库的普通问题
